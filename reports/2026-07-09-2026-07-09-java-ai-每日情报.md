## 五、对 Java 开发者的实际启发

- Java AI 应用框架正在形成两条主线：一条是 Spring AI 这类 Spring 原生抽象，另一条是 LangChain4j、Semantic Kernel 这类偏应用编排的 SDK。团队选型时应先明确是做业务应用接入，还是做统一 AI 平台。
- MCP 值得持续关注。`modelcontextprotocol/java-sdk` 说明 Java 服务可以更标准化地暴露为模型可调用工具，后续企业内部 CRM、订单、知识库、工单系统都可能通过 MCP 接入 Agent。
- RAG 的工程重点不只是“能问答”，还包括文档切分、元数据设计、引用来源返回、权限过滤、召回评测和日志观测。今天的小任务可以直接沉淀为团队 RAG 模板。
- 从 Hugging Face “Data for Agents”和 OpenAI “Docs MCP”等背景信息看，Agent 的竞争点正在从单次模型调用转向数据、工具、协议和上下文工程。Java 后端开发者的优势在于系统集成、权限治理、稳定性和可观测性。
- 工作流与流程治理仍然重要。类似 `operaton/operaton` 的 BPMN 项目可与 Agent 编排结合，用于处理人工审批、失败补偿、任务状态跟踪和企业级审计。
